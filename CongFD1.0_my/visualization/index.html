⑥ 快速复习卡

1. 跑一次算例的最短路径？
运行目录放 16 值 info.txt → 构建 → 目录内执行 build/congFD。
2. endStep 与 outputDt？
endStep＝输出次数；总时长＝endStep×outputDt；dt 由 CFL 自适应。
3. 幽灵层几层？
4 层（WCNS5＋MND6，由 nGhostCell() 给出）。
4. dt 怎么定？
dt＝CFL / Σ_d max(|u_d|+c)/h_d（按维通用，3D 直接可用）。
5. 重构走"特征"还是"逐分量"？
特征：Roe 平均 → 特征系统 → 特征变量 5 点插值 → 回原始量。3D 特征系统已就绪（任务 4）。
6. 为什么重跑能对 6 月存档？
确定性计算＋同一工具链；比对用 h5diff（HDF5 带时间戳，cmp 不可达）。
7. 加新算例要改哪里？
命名表/预设（zoneMain＋info.cpp）→ solInit 加 case →（如需）initBnds → 运行目录放 info.txt。
8. 三维现在到哪一步了？
任务 0–8 全部完成：三维核验三腿通过＋外部真值验证（熵波 vs 解析解 4.4–4.8 阶）；下一：任务 9 四格式 64³ 实算出图。
9. git 怎么走？
已按任务分批提交 7 笔（v3.1.4–v3.1.10，本地）；推送手动——待推送 8 笔（含基线 92587aa）。
10. 格式族谱一句话？
WENO→WCNS/TCNS→TENO 族（TENO=TCNS5 / TENO-S / TENO-A）→ 所提 TENO-AS；全在 interScheme.hpp。
