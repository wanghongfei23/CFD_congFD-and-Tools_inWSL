## 5. 外部真值验证一：TGV 镜像对称检验 ✅

## 6. 外部真值验证二：熵波（解析解逐点对比）✅

## 7. 过程记录：两例"边界污染"事件（测试设计缺陷，非代码缺陷）

- **现象**：等熵涡（nCase=2，涡轴/平流沿体对角）与初版熵波（波矢 (1,2,3)/√14）——Linf ≈ 0.4–0.8、误差自域角落生长扩散、不收敛（51% 格点污染 @ t=2）
- **排查**（逐项排除）：
  - 线编号与装配：getOneDBnd 公式 ↔ 六面 OneDBnd 装配 ↔ calOffset/calOffsetInverse 语义 ↔ SpDistributor 遍历序——四处完全自洽
  - Roe 通量/特征系统：3D 版与 2D 正确版逐行对照——结构一致（含剪切行分配、熵修正）
  - 时间与解析实现：t=0 场与解析逐位一致（Linf=0），排除初值实现错误
- **归因**：两类初值在 2π 周期域上**非严格周期**——涡场在缝合面两侧值不匹配（差 ~0.25，因涡心不在周期固定点）；归一化波矢分量非整数（(1,2,3)/√14 ∉ ℤ³）。周期回卷把人为不连续缝入 → 边界错缝注入伪波 → 自角落生长
- **判定实验**：同一构建、仅初值波矢不同（整数 (1,1,1)，严格周期；该次运行的源码状态未入库——原始数据保留于 runs/wav_n33/ 与 runs/wav2_*，可用 `tools/incident_stats.py wave_old <cgns> 0.01` 复算占比 51.13%→0.00%）→ 全域 0 污染、4.4–4.8 阶收敛 → **代码无缺陷成立**
- **处置**：nCase=2（等熵涡）保留代码但不作判决测试（如未来使用须改为大域或周期化初值）；本事件完整留档

## 8.6 参照实现对照：2D↔3D code-to-code（2026-09-17 增补）

### 8.6.1 过程中暴露并修复的隐藏缺陷（面线号 stride）

- **现象**：对照程序首次运行即段错误（`oneDBnds` 出现空槽，Bnds::update 遍历到 null）。
- **定位**：面"线号"公式 `(i+j*iMax[2])*2` 的 stride 误用了"后一维尺寸"，而非行主序快维尺寸——
  **等边网格（nx=ny=nz，此前全部算例）下恰好构成双射，从未暴露**；**不等边网格（z 格数≠x/y）立即撞车**（线号重叠→空槽/边界数据错配）。
- **修复**（共 6 处，均带注释）：`getOneDBnd`（bnds.cpp）×3 与 3D 六面装配（initializer.cpp）×3 的 stride 统一改为快维尺寸（x 线→iMax[1]；y/z 线→iMax[0]）。
- **零影响核验**（修复不改既有结论的证据）：
  - 2D 老路径 j 恒 0、两式数学恒等 → **2D 回归 h5diff 数据级零差异（实测）**；
  - 3D 等边两式恒等 → **同一算例修复前后逐位比对（wav2 17³，t=2）h5diff 零差异（实测）**；
  - 3D 冒烟（17³ TGV）正常结束。
- **使用约束（如实记录）**：单向格数须 ≥ 幽灵层数（当前配置 spMethod=WCNS5+diffMethod=MND6 → **nGhost=4**）；
  实测 z=8 格通过、z=2 格越界（幽灵层回卷需绕域多圈，超出 OneDBnd 单次映射能力）。



- **通过**：纯性（逐位）、线程确定性（逐位+全场）、TGV 收敛 p=4.69、TGV 对称性 1.7e-14、熵波外部真值 4.4–4.8 阶
- **未覆盖**：与 Fu 2018 图 24 / Brachet 1984 的 TGV 定量对比（任务 9）；超长时（t=10）稳定性（任务 9）；跨平台/跨编译器复现（未测）
